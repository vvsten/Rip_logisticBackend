# Описание таблиц базы данных

## Таблица 1 – Таблица transport_services

| Атрибут | Тип данных | Описание |
|---------|------------|----------|
| id | INTEGER | Первичный ключ, идентификатор транспортной услуги |
| name | VARCHAR(255) | Название транспортной услуги |
| description | TEXT | Описание транспортной услуги |
| image_url | VARCHAR(500) | URL изображения транспортной услуги |
| price | DECIMAL(10,2) | Цена транспортной услуги |
| delivery_days | INTEGER | Срок доставки в днях |
| weight | FLOAT | Вес груза |
| length | FLOAT | Длина груза |
| status | VARCHAR(20) | Статус транспортной услуги |

---

## Таблица 2 – Таблица logistic_request_services

| Атрибут | Тип данных | Описание |
|---------|------------|----------|
| logistic_request_id | INTEGER | Внешний ключ на id из таблицы logistic_requests, первичный ключ |
| transport_service_id | INTEGER | Внешний ключ на id из таблицы transport_services, первичный ключ |
| comment | TEXT | Комментарий к услуге в заявке |
| quantity | INTEGER | Количество услуг в заявке |
| position | INTEGER | Позиция/порядок услуги в заявке |

---

## Таблица 3 – Таблица logistic_requests

| Атрибут | Тип данных | Описание |
|---------|------------|----------|
| id | INTEGER | Первичный ключ, идентификатор логистической заявки |
| status | VARCHAR(20) | Статус заявки |
| creator_id | INTEGER | Идентификатор создателя заявки, внешний ключ на id из таблицы users |
| weight | FLOAT | Вес груза |
| length | FLOAT | Длина груза |
| created_at | DATETIME | Дата и время создания заявки |
| formed_at | DATETIME | Дата и время формирования заявки |
| completed_at | DATETIME | Дата и время завершения заявки |
| moderator_id | INTEGER | Идентификатор модератора, внешний ключ на id из таблицы users |

---

## Таблица 4 – Таблица users

| Атрибут | Тип данных | Описание |
|---------|------------|----------|
| id | INTEGER | Первичный ключ, идентификатор пользователя |
| login | VARCHAR(150) | Логин пользователя |
| password | VARCHAR(128) | Пароль пользователя |
| is_moderator | BOOLEAN | Флаг «является ли пользователь модератором» |
